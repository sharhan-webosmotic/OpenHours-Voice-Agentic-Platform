# 1. Overview

Penwise wants students to write class notes by hand on pen tablets.

# 2. What We Will Build

## MVP

1. **Handwritten Notebook**
   - **Pen writing** with page tools
2. **Shared Notes**
   - **Teacher handouts** pushed to every tablet
3. **Accounts and Schools**
   - **School login** for students and teachers

## Phase 2: Teacher Tools *(tentative)*

1. **Teacher View**
   - **Class inbox** of each student's notes
