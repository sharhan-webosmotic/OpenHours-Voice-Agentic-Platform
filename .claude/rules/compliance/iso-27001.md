# ISO/IEC 27001 — required controls (checklist)

> Loaded by `/audit` when `compliance:` includes `iso-27001` or `iso27001`. The ISMS
> standard (2022 revision). Heavily overlaps `soc2.md`: if both are in scope, run `soc2`
> and add the ISO-specific ISMS artifacts below.

## Information Security Management System (ISMS)
- [ ] **Scope** of the ISMS documented.
- [ ] **Information security policy** approved by management (`docs/security-policy.md`).
- [ ] **Risk assessment + risk treatment** methodology and results (`docs/risk-register.md`).
- [ ] **Statement of Applicability (SoA)**: which Annex A controls apply, and why excluded
  ones are excluded.
- [ ] **Management review** + **internal audit** performed and recorded.
- [ ] **Continual improvement**: corrective actions tracked.

## Annex A control themes (2022: 93 controls in 4 themes — testable subset)
- [ ] **Organizational**: access control policy, supplier security, incident management,
  threat intelligence, cloud-service security.
- [ ] **People**: onboarding/offboarding, awareness training, confidentiality agreements.
- [ ] **Physical**: covered by the cloud provider attestation for hosted infra.
- [ ] **Technological**: MFA, least privilege, cryptography, secure development, logging
  and monitoring, backup, data masking, web filtering, secure configuration, vulnerability
  management.

## Verification (lean)
`/audit` checks:
- `docs/security-policy.md`, `docs/risk-register.md` exist → CONCERNS if missing.
- A Statement of Applicability or control matrix exists → CONCERNS if missing.
- CI requires PR review; dependency scanning in CI (shared with `soc2.md`).
- TLS only; encryption at rest; MFA referenced in admin auth.
- Audit logs configured + retained (see `audit-logs.md`); backup strategy documented.
